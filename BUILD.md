# Résumé source and build

The résumé content lives in [`design/resume-data.json`](design/resume-data.json).
The shared [`design/build_resume.py`](design/build_resume.py) produces the
one-page PDF and accessible HTML. The viewer styles are maintained separately in
[`website/resume.css`](website/resume.css).

Use Python 3.10 or newer and the dependency versions in `requirements.txt`:

```bash
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -B scripts/build_resume.py --check
```

`--check` validates the content and compares the generated bytes in memory with
the committed outputs. It does not overwrite files.

After an intentional content change, rebuild with:

```bash
python3 -B scripts/build_resume.py
python3 -B scripts/build_resume.py --check
```

The repository entry point also keeps `VADLA HEMANTH RESUME.pdf` identical to
`website/assets/Vadla-Hemanth-Resume.pdf`, so previously shared file links keep
working. The original résumé remains available in Git history.

ReportLab supplies the embedded Vera fonts; no font downloads are needed.
The builder rejects page overflow rather than shrinking the text. Review the
rendered PDF and HTML after changing content or layout.

To view the local HTML:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory website
```

Open [the local résumé](http://127.0.0.1:8000/resume.html). Its portfolio link
returns to [the public portfolio](https://portfolio.hemanthvadla.tech/).
